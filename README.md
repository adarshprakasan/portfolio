# Adarsh Prakasan — Designer × Developer Portfolio

Starter implementation of the dual-profile homepage concept.

## Stack
- Next.js
- TypeScript
- Tailwind CSS v4
- Motion
- React Three Fiber / Three.js (dependency ready for the next iteration)
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
